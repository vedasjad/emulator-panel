# Changelog

## 0.1.0

First public preview. macOS only.

- Device Manager in the activity bar with separate Android and iOS sections: run, stop, cold boot, wipe data, delete, reveal files and edit `config.ini` for AVDs; run, stop, erase and delete iOS simulators.
- Running Devices tab that streams one or more emulators side by side, with touch, scroll, keyboard input and a toolbar for Back, Home, Overview, volume, power, rotation, screenshots, Location and Extended Controls.
- `Cmd+A`, `Cmd+C`, `Cmd+X` and `Cmd+V` in emulators and mirrored phones, sharing the Mac clipboard.
- The emulator's own extended controls (Location with route playback, Cellular, Battery, Sensors, Snapshots and more), because emulators run with their window hidden instead of headless.
- Mirroring of Android phones over USB or Wi-Fi through the bundled scrcpy server, with configurable size, frame rate and bit rate.
- Separate Running Devices window that opens where you last left it and stays open when its devices stop.
- Running Devices column that fits its devices, keeps its width when the sidebar or window changes, and never receives newly opened files.
- iOS simulator location tools: set a point, play a GPX or KML route at a chosen speed, or run one of Apple's built-in scenarios.
- Screenshots saved to a folder and copied to the clipboard.
